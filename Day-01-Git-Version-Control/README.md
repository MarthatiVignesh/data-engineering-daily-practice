# Day 1 - Git and GitHub Practice

## Objective

To understand Git version control and practice the basic Git workflow using Ubuntu and GitHub.

## Git Configuration

- git --version
- which git
- git config --global --list

## Git Repository Basics

- git init
- git status
- git add
- git add .
- git commit

## Git History

- git log
- git log --oneline
- git log --oneline --all
- git log --oneline --all --graph
- git show

## Comparing Changes

- git diff
- git diff --staged

## Branching

- git branch
- git branch <branch-name>
- git switch <branch-name>
- git checkout <branch-name>
- git checkout -b <branch-name>
- git branch -M main

## Merging

- git merge <branch-name>
- git branch -d <branch-name>

## File Operations

- git reset <file>
- git rm <file>
- git mv <old-file> <new-file>

## Tagging

- git tag
- git show <tag-name>
